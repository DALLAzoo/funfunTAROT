# In-between Shift — 1장 타로 독립 시험본

## 실행
ES modules 사용으로 `file://` 직접 열기는 브라우저에서 제한될 수 있습니다. 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 방문. VS Code Live Server도 가능합니다.

## 구현
- 탭 진입 시 덱 뒷면 무작위 선택
- 셔플 시 직전과 다른 뒷면을 선택(2종 이상 등록된 경우)
- 한 덱의 모든 카드는 동일한 뒷면
- 공중 부유 → 입체 교차 셔플 → 한 뭉치 → 부채꼴 펼침 → 카드 선택 → 앞면 공개
- 셔플 반복 가능, 상태별 입력 제한, 모션 감소 환경 대응
- CSS, 데이터, 뒷면 설정, 렌더링, 애니메이션, 컨트롤러 분리

## 주의
- **독립 프로토타입**이며 기존 사이트의 최신 코드와 통합/대조하지 않았습니다.
- SVG 뒷면 3종은 **임시 디자인**으로 사용자 원본 이미지가 아닙니다.
- 앞면은 시연용 22장 이름/기호입니다. 실제 78장 앞면과 리딩 기능은 미구현입니다.
- 성능/모바일 브라우저 실기기 검증 미완료.
- 무늬 중복 방지는 제안 동작으로 구현되어 있으며 변경 가능.

## 뒷면 추가
1. `assets/card-backs/`에 이미지 파일을 넣습니다.
2. `js/back-config.js`의 `backs` 배열에 id/name/url을 추가합니다.
3. `js/card-animation.js`를 수정할 필요가 없습니다.

## 파일 책임
- `index.html`: 마크업
- `css/tarot.css`: 타로 탭 전용 스타일
- `js/main.js`: 상태와 버튼 이벤트
- `js/card-animation.js`: 움직임
- `js/card-view.js`: 카드 DOM 렌더링
- `js/card-data.js`: 데모 앞면 데이터
- `js/back-config.js`: 뒷면 데이터와 랜덤 선택
