# 최종 반영 전 결정할 항목

작성: Codex / 2026.10.29

## 20장 구성 정책

| 후보 | 동작 | 필요한 결정 |
|---|---|---|
| 승인된 20장 목록 | explicit-ids에 정한 ID만 탐색 | 어떤 20장인지 사용자가 지정 |
| 전체 22장 탐색 | selection을 22로 변경, 화면은 3장 유지 | 20장 제한 대신 전체 덱을 사용할지 결정 |
| 매번 무작위 20장 | 이번 시험의 trial-uniform-subset | 임시 시험 방식을 최종 정책으로 채택할지 결정 |

이번 작업은 특정 두 장을 고정 제외하지 않았다. 실제 상담의 확률 정책을 확정하지 않는다. 셔플에 쓰는 시각 카드 수와 탐색 대상 수는 별도 설정이다.

## 결과 공개 방식

- 기본 시험: 결과 위치로 들어온 뒤 뒤집기(flip-after-arrival).
- 비교안: 들어오는 동안 뒤집어 앞면으로 도착(front-on-arrival).
- 두 방식은 설정으로 비교 가능하며 최종 선택은 미확정이다.

## 실제 앞면 자산

기준 ZIP에는 실제 앞면 이미지가 없다. 현재 기본 결과는 시연이다. 실제 이미지와 카드 ID의 등록이 필요하다. 이번에는 라이브러리의 다른 타로 이미지를 임의로 골라 연결하지 않았다.

## 남은 검증

실제 휴대폰 터치·초록색 면 발광 원인 재현, 저사양 FPS·발열, Safari/Firefox, 78장 실제 이미지, 긴 반복 실행, 전환 도중 화면 회전, 상담·예약과의 통합, 프레임별 덜컥거림 영상 비교가 남아 있다.
