# AD4 — 태블릿·PC 가로 결과 화면: 설명창 아래 배경 여백 정리 (2026.11.13)

## 변경 내용
- 대상: 가로형 결과 화면 중 태블릿의 `roomy-touch-landscape`, 일반 PC(가로 1100px 이상, hover/fine) 배치.
- 제목 아래 카드·설명창을 하나의 결과 묶음으로 보고, 묶음 위 여유 공간과 아래 버튼까지 배경 여유 공간을 비교해 함께 아래로 이동.
- 글이 짧으면 내려가고 길면 이동량이 줄어들며, 여유가 없으면 이동하지 않는다. 버튼 좌표는 유지한다.
- 수정 코드: `css/screen/24-landscape-responsive-scale.css`, `js/screen/app/reading-scroll-cue.js`.
- 카드·설명창 크기, 글자 크기, 본문, 텍스트 안쪽 패딩, 이미지·오디오, 셔플·팬·카드 공개 기능은 변경하지 않음.
- 모든 세로 화면 및 스마트폰/폴더블 짧은 가로 화면은 변경하지 않음.

## 검증
- Chromium에서 7개 뷰포트 × 짧은/긴 본문 = 14개 조건의 결과 화면 및 겹침 검증.
- iPad mini 1024×768, iPad Pro 1376×1032, PC 1366×768·1440×900: 여유 공간이 있을 때 이동 계산 확인.
- 800×360 스마트폰 가로, 360×800 스마트폰 세로, 960×1440 태블릿 세로: 이동량 0.
- iPad mini 가로와 PC 1366×768: 실제 JS 모듈을 오프라인 Chromium에서 실행해 셔플 → 부채꼴 → 두 번 선택 → 결과 공개 완료, JS 오류 없음.
- 실제 결과 화면은 출력한 카드 종류·글 길이에 따라 이동량이 달라진다.
- 아이패드/맥 Safari, 실제 카드 PNG 및 GPU 효과 전체 확인은 미완료. 시험본이며 배포하지 않음.
