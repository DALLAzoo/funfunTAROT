# AD5 — 카드 모서리·외곽선 조합 통합 수정 (2026-11-13)

## 기준과 범위
- 입력 ZIP: `InBetweenShift_AD5_portrait_dropdown_ratio_20261113.zip`.
- 사용자 지정 문제: 셔플 및 카드 움직임 도중 **실제 카드의 테두리 특히 모서리의 선**이 순간적으로 옅어지거나 사라져 보이는 현상. 메뉴의 테두리 문제가 아님.
- 목표: 기존 이미지 위에 별도 가짜 테두리·가림층을 덮지 않고, 기존 3D 카드 표면 자체에서 원인 조합을 정리한다.
- 사용자의 승인된 이미지·조명·움직임·배치·기기별 비율 계산을 보존한다.

## 확인한 조합
1. 모든 WebP 카드 뒷면 20종의 꼭짓점은 투명(alpha=0)이다. 실제 배경 이미지는 카드 실루엣 전체를 채우지 않는다.
2. 셔플 상태에서 앞뒷면은 `border:0!important`가 적용되고, 외곽선은 `0 0 0 .6px rgba(...,.22)` 그림자에 의존했다. 이는 3D 회전·소수 픽셀·축소 시 약하게 표시된다.
3. 카드 크기가 달라도 기본 `--card-radius:8px`가 대부분 유지돼, 뒷면 이미지 고유의 비례적인 둥근 모서리와 차이가 생겼다.
4. 드래그에서는 비선택 카드의 그림자를 의도적으로 제거하지만, 이때 테두리까지 그림자로 그려진 경우 카드 실루엣이 약해질 수 있다.

## 기존 코드 안에서 통합한 수정
- `css/decoration/cards.css`
  - `#stage` 카드 반경을 실제 카드 폭과 같은 비율로 계산: 원본 640px 폭에 대략 25px 곡률 기준, 2~12px 범위.
  - 실제 `.card-face`에 1~1.5px 크기의 갈색·금빛 계열 **물리적 테두리**를 설정. 셔플/부채꼴/드래그 모두 같은 표면 규칙으로 적용.
  - 투명한 WebP 꼭짓점 뒤에 원래 카드 어두운 배경색에 가까운 바탕을 적용해 모서리 빈 영역을 없앰. 새 DOM 요소/가림층/가짜 테두리 없음.
  - 앞뒷면의 `border:0` 충돌과 0.6px 외곽 그림자 의존 제거. 기존 낙하 그림자는 유지.
- `css/effects/09-card-surface-performance.css`
  - 셔플 중 뒤집혀 보일 수 있는 두 번째 면에도 같은 바탕색을 사용하도록 변경하고, 표면 테두리를 지우던 규칙을 제거.
  - 성능 최적화(드래그 그림자 제거·마스크 애니메이션 일시 정지), 단계별 카드 측면 표시 및 결과 카드 분리 규칙은 그대로 둠.
