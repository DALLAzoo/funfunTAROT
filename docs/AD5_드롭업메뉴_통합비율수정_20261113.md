# AD5 드롭업 메뉴 전체 기기 통합 비율 수정 (2026-11-13)

## 기준
- 기준본: `InBetweenShift_AD5_card_corner_integrated_fix_20261113.zip`
- 직전 통합 시험본을 보완했으며 기존 카드 중심형 스마트폰 가로 레이아웃은 포함하지 않음.
- 별도 덮어쓰기 CSS 파일은 만들지 않음. 드롭업 메인 버튼, 카드, 셔플, 결과 배치, 애니메이션 로직을 유지함.

## 통합 구조
- 모든 화면에서 펼쳐지는 메뉴 너비 = 메인 드롭업 버튼 너비의 88%, 우측 정렬, 외곽 테두리 없음.
- 메뉴 항목의 글자/높이/여백/간격을 한 묶음의 CSS 변수로 계산.
- 공통 메뉴 렌더링의 단일 책임 파일: `css/screen/01-foundation-and-cards.css`.
- 세로 화면: `23-portrait-responsive-scale.css`의 AD4 X/Y 비율을 그대로 이용.
- 터치 가로 화면: `24-landscape-responsive-scale.css`의 AD4 UI 배율과 버튼 높이를 이용.
- 짧은 스마트폰/폴더블 가로 화면: `25-landscape-adaptive-layout.css`의 실제 버튼 높이와 연동.
- PC·노트북 가로 화면: `01-foundation-and-cards.css`에 기존 PC 44px 버튼을 기준으로 뷰포트 너비·높이에 따른 메뉴 글자/간격 변수 계산을 통합. 기존 PC 메인 버튼은 수정하지 않음.
- 태블릿 가로의 `19-phone-portrait-lock-tablet-result.css`에 남아 있던 고정 44px 메뉴 높이·간격 중복 규칙을 제거. `20-tablet-landscape-fixed-actions.css`는 기존 메뉴 중복 규칙 제거 상태 유지.
- 메뉴는 메인 버튼보다 작게 보이도록 하고, 항목 3개가 보이는 높이까지만 확장하며 추가 항목은 메뉴 내부에서 스크롤.

## 검증 범위
- Chromium에서 사이트 CSS 로딩 순서를 보존한 DOM 시험: 스마트폰, 폴더블, iPad/태블릿, 노트북/PC(가로·세로) 17개 뷰포트.
- 17/17 메뉴 너비 비율 88%, 메뉴와 선택 항목 외곽 테두리 0px, 항목 높이 ≤ 메인 버튼 높이의 105%, 5개 항목에서 내부 스크롤, 메뉴 최대 높이 충족.
- 실제 사이트 전체 애니메이션 실행·실기기 렌더링은 확인되지 않음. 검증 범위를 벗어나는 작동을 완료로 표시하지 않음.
- 기존 JS·이미지·음원·메인 버튼 위치 및 애니메이션 코드는 변경하지 않음. GitHub/배포 원본 변경 없음.
