# AD4 태블릿 세로 설명 영역 검증 및 통합 기록

작성일: 2026-11-13 KST
기준: `InBetweenShift_AD4_700px카드크기연속화_전체시험본_20261112.zip`
상태: **시험본 (실브라우저 검증 미완료)**

## 사용자 요구
- 스마트폰 세로·가로와 PC 등 이미 만족한 디자인의 크기와 위치는 그대로 유지한다.
- 태블릿 세로 결과 화면(iPad mini, Surface Pro 포함)에서 카드·제목·문구·버튼의 공간 관계를 확인한다.
- 기존 CSS/JS 책임을 변경하며 새로운 우선순위 덮어쓰기 파일을 누적하지 않는다.
- 셔플 중 카드 확대·축소와 부채꼴 기하를 바꾸지 않는다.

## 관찰과 원인
- 이전 캡처에서 태블릿 세로의 문구 상자 높이가 서로 다르게 나타났다.
- `23-portrait-responsive-scale.css`에서 결과 문구의 상위 그룹은 `flex:1 1 auto`로 남는 높이를 받지만 실제 문구 박스는 `flex:0 1 auto`로 내용의 높이부터 고려하도록 설정돼 있었다.
- 같은 파일에 이미 존재하는 **터치 태블릿 세로** 조건에서 문구 박스의 `flex`만 수정했다. 별도 기기 모델명 분기 추가 없음.

## 수정 파일과 내용
- `css/screen/23-portrait-responsive-scale.css`: 기존 터치 태블릿 세로 결과 문구 선택자에 `flex:1 1 auto` 적용.
- 문구 박스는 상위 그룹이 확보한 높이를 채우되, 내용이 길면 기존 `overflow-y:auto`로 내부 스크롤한다.
- 카드의 계산값, 제목과 버튼 크기·위치, 애니메이션 수치, 반응형 경계, 페이지 구조, 리딩 내용은 변경하지 않았다.

## 검증 범위
- ZIP 엔트리·CRC 검사 통과, 소스의 단일 CSS 수정 및 기능 파일 해시 동일 여부 확인.
- 기존 CSS의 태블릿 세로 조건, 결과 문구 선택자 및 `overflow-y:auto` 유지 확인.
- **미확인:** 브라우저 최종 렌더링에서 문구 상자가 실제로 얼마나 커지는지, iPad mini·Surface Pro 실기기 스크롤과 화면비, 전체 카드 공개 동작.
- 카드 크기를 다시 조절하거나 PC 비율로 강제 맞춘 수정본이 아님. 이 한 가지 수정이 전체 UI 비율 문제를 해결했다고 판단하지 않는다.

## 영향 범위
- 변경: 터치 태블릿 **세로 결과 문구 상자의 공간 배분**
- 변경 없음: 카드뭉치, 첫 셔플, 부채꼴, 카드 선택/공개, 태블릿 가로, 스마트폰, PC, 폴더블(태블릿 세로 화면 조건에 해당하는 경우는 동일 CSS 적용 가능)
