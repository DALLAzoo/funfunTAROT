# 4차 수정 — 2026-10-30

- 기준: 3차 수정본 ZIP. 기존 PNG 8장 무변경.
- 공개: 결과 카드 DOM을 최종 중앙 호스트에 먼저 배치하고, 같은 요소의 내부 면을 0→180도로 연속 회전. 90도 중간 DOM 교체 삭제. 회색 막·와이프·페이드 사용하지 않음.
- 셔플: 사전 계산된 각 시점의 카드 위치를 비교해 화면 위치와 깊이가 동시에 근접한 카드끼리 완만하게 분리하는 경로 보정 추가. 마지막 의도된 카드 쌓기는 예외.
- 셔플 카드 측면의 불투명 재질 레이어 숨김. 카드 뒷면 PNG 및 셔플 카드 크기·속도 설정 유지.
- 제한: CSS 3D는 실제 강체 충돌 시뮬레이션이 아니며, 모바일 브라우저 실기기에서 모든 관통·GPU 합성 문제의 해소는 미검증.
- 앞면 이미지가 등록되지 않은 카드는 기존 베이지색 시연용 앞면을 표시함.
