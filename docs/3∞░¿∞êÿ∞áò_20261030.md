- 셔플 카드의 앞/뒤 양면 모두 동일한 원본 뒷면 PNG를 표시하도록 셔플 전용 CSS 적용. 회전 중 데모 앞면의 회색/베이지색 배경이 보이지 않게 처리.

- 카드 크기, 셔플 궤적, 속도, 뒷면 PNG 파일은 변경하지 않음.
